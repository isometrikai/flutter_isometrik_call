# isometrik_flutter_call_example

Demonstrates how to use the isometrik_flutter_call plugin.

## Configuration (secrets)

Credentials live in `example/.env` (loaded via [flutter_dotenv](https://pub.dev/packages/flutter_dotenv)). That file is **gitignored** so it is not pushed to GitHub.

1. Copy `.env.example` to `.env` in this directory.
2. Fill in the `ISOMETRIK_*` variables. Optional URL keys default to public Isometrik endpoints if omitted.
